# Bangla Date Today - বাংলা তারিখ

A free, real-time online tool to check today's **Bangla Date (বাংলা তারিখ)**, English Gregorian date, Hijri (Islamic) date, Bengali year/month, day name, and time for both India and Bangladesh.

**Live Demo:** [https://bangladate.netstudy.in/](https://bangladate.netstudy.in/)

## Features

- Displays current **Bangla Date** (বাংলা তারিখ) instantly
- Shows Bengali year (বাংলা সাল), month (মাস), and day of the week (বার)
- Real-time **English Date** (Gregorian) and day name
- Accurate **Hijri/Arabic Date** (ইসলামিক/হিজরি তারিখ)
- Separate time display for **India (IST)** and **Bangladesh (BDT)**
- Fully responsive and mobile-friendly design
- No login or installation required – 100% free
- Auto-updates in real-time (live clock)

## Why Use This Tool?

- Quickly know today's Bangla date without manual calculation
- Useful for Bengalis in India, Bangladesh, and worldwide
- Helpful for cultural events, festivals (Pohela Boishakh, Durga Puja, etc.), horoscopes, and official purposes
- Accurate conversion between Bangla, English, and Hijri calendars
- Great alternative to apps or complex calendar converters

## How It Works

1. The tool fetches current UTC time and converts it to:
   - Bangla Calendar (Bengali San 143x)
   - Gregorian Calendar
   - Hijri Calendar
2. Displays day names in both Bangla (বুধবার) and English (Wednesday)
3. Shows local times for India (🇮🇳) and Bangladesh (🇧🇩)

Supports Bangla calendar rules including the adjustment for Ashwin month and regional variations.

## Tech Stack

- Frontend: HTML5, CSS3, Vanilla JavaScript (or minimal framework)
- Date conversion logic: Pure JavaScript (no heavy libraries)
- Responsive design with Bootstrap or custom CSS
- Real-time updates via setInterval()
